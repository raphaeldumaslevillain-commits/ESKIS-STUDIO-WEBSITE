Le portfolio

Les visuels du portfolio proviennent des fichiers fournis par le propriétaire du site. Ils sont sélectionnés et optimisés pour l’affichage sur le web. Les créations et marques présentées restent la propriété de leurs titulaires respectifs.

Formulaire et données

Le formulaire prépare un brief téléchargeable. Il n’envoie aucun e-mail et ne transmet pas les informations saisies à Eskis. Le choix du thème est enregistré dans le stockage local du navigateur. Aucun outil publicitaire ou de mesure d’audience n’est ajouté. Le site est hébergé par GitHub Pages.

Éditeur

Nom légal, statut, adresse, immatriculation et contact professionnel : à compléter avec les informations réelles de l’activité avant la mise en service commerciale.

Composants et références

Les boutons principaux adaptent le code de « Liquid Metal Button » fourni par le propriétaire du site le 20 octobre 2026. Le métal animé utilise Liquid Metal de Paper Shaders 0.0.81 (Apache-2.0), hébergé localement ; notices dans les ressources. Boutons HTML natifs, largeur adaptative, textes contrastés, clavier et réduction des animations sont pris en charge.

L’ouverture 3D est adaptée de Horizon Hero Section (lovesickfromthe6ix). La page et la fenêtre de méthode reprennent la géométrie et les interactions de Radial Orbital Timeline (jatin-yadav05). Les codes de ces deux composants ont été fournis par le propriétaire du site, puis adaptés en JavaScript pour le site statique.

Le titre à mots animés, la galerie incurvée, les dossiers de services et le formulaire sont des réimplémentations spécifiques à partir des aperçus de Animated Hero (Tommy Jepsen), Tilted Grid Hero (Ruixen UI) et Contact Form (meschacirung). Les quatre catégories et le dossier des possibilités adaptent les dossiers givrés de services, recréés à partir de l’aperçu de Glassmorphism Folder Cards (kedhareswer) : inclinaison au pointeur, assemblage au défilement et fiches en éventail. Leur code original n’a pas été récupéré.

La réfraction est adaptée de LiquidGlass (manfromexistence), précédemment récupéré via le MCP 21st.dev. Le moteur de matière liquide conservé dans les ressources provient de Liquid Sculpture Hero (Guglielmo Giannattasio). Le paysage utilise Three.js et GSAP, hébergés localement. Les licences et attributions accompagnent les sources.

Identité et typographies

Tracés du logo fournis par leur propriétaire, conservés en version monochrome. DM Sans est hébergée localement sous licence SIL Open Font License. Les informations de licence sont incluses avec les fichiers.
